# API Inteligente de Orçamento Financeiro com Spring AI

Esta aplicação é uma API REST desenvolvida em Spring Boot e Spring AI para automação e gestão financeira pessoal através de comandos de voz e inteligência artificial.

## 🚀 Tecnologias e Recursos

- **Spring AI:** Integração com modelos de linguagem e áudio.
- **Speech-to-Text (STT):** Transcrição automática de comandos de voz do usuário em texto.
- **Tool Calling (Function Calling):** Acionamento automático de rotinas Java para registrar transações e consultar saldos no banco de dados.
- **Text-to-Speech (TTS):** Geração de áudio para resposta sintetizada à pessoa usuária.
- **Spring Data JPA & H2:** Persistência de dados financeiros.
